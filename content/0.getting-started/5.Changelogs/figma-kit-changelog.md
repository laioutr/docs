## Figma Kit Changelog

Release notes for the Laioutr Figma Kit are **not maintained on this documentation site**. Use the sources below so designers always see **what changed** in the same place they use the libraries.

### Inside the Figma kit

1. **Open the published library file** in Figma (the same `.fig` / team library you enabled for variables and components).
2. In the **left sidebar**, check the **Pages** list for a page named for release history—for example **Changelog**, **Release notes**, **What’s new**, or similar (exact naming can vary by library file).
3. That page is the **canonical changelog** for that kit: read it whenever you pull an update or before adopting new components.

If you consume the kit as a **published team library**, open the **source file** from your team project (or duplicate from Community) to reach those pages; linked instances alone do not always surface the full document structure.

### When Figma notifies you about library updates

After you **enable** a Laioutr library, Figma may show **library update** prompts in the editor. Accepting an update can surface **short release notes** in the update dialog—use that as a quick summary, then open the kit’s **Changelog** page above for full detail.

### Laioutr on Figma Community

All public Laioutr kits and creator activity are listed on our **Figma Community profile**:

[https://www.figma.com/@laioutr](https://www.figma.com/@laioutr)

From there you can:

- Open each **library** and its **Community listing** (description and version context).
- **Follow** [@laioutr](https://www.figma.com/@laioutr) to see new publishes and updates in your Community feed.

For **which file changed** and **narrative release notes**, prefer the in-file changelog page plus your team’s library update notifications.
