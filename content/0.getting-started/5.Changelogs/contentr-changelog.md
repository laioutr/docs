All notable changes to **Contentr** are documented here, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [2026-11-04]

### Fixed

- Pasting formatted text into a rich text field no longer fails.

## [2026-10-29]

### Added

- New projects get Contentr with their Sites or Commerce licence; existing projects keep it.

## [2026-10-27]

### Added

- The login can ask for an hCaptcha check, and Contentr's menu shows icons.
- An entry now shows how far each language is filled in.
- Contentr has a new look: collections beside their entries and a read-only Schemas page.
- Collections now live under Contentr in the project menu.

## [2026-10-19]

### Added

- A menu can be published before it has items.
