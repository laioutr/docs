When you ask Cursor about `defineSection`, or Claude Code about an Orchestr query, you want it to quote this documentation rather than guess from training data. The Laioutr docs expose an **MCP (Model Context Protocol) server** at [`https://docs.laioutr.com/mcp`](https://docs/mcp) that serves the same content you are reading right now, so any MCP-aware client can search and cite these pages in its answers.

This server only exposes the documentation site. It does not connect to your project, your Cockpit, or your data.

## One-click install

::tip
Install buttons generate the correct config for your IDE and open it in a deeplink. Use the manual steps below if you prefer to edit config files yourself.
::

:install-button{ide="cursor" url="https://docs.laioutr.com/mcp"}

:install-button{ide="vscode" url="https://docs.laioutr.com/mcp"}

## Manual setup

::tabs
  :::tabs-item{label="Claude Code"}
  Add the server from the CLI:

  ```bash
  claude mcp add --transport http laioutr-docs https://docs.laioutr.com/mcp
  ```

  Then restart Claude Code. Verify with `claude mcp list`.

  Alternatively, install the [Laioutr Claude Code plugin](/getting-started/hints-and-tips/claude-marketplace), which registers this MCP server alongside Laioutr-specific skills and conventions.
  :::

  :::tabs-item{label="Cursor"}
  Edit `~/.cursor/mcp.json` (or `.cursor/mcp.json` in your project):

  ```json
  {
    "mcpServers": {
      "laioutr-docs": {
        "url": "https://docs.laioutr.com/mcp"
      }
    }
  }
  ```
  :::

  :::tabs-item{label="VS Code"}
  Edit `.vscode/mcp.json` in your workspace:

  ```json
  {
    "servers": {
      "laioutr-docs": {
        "type": "http",
        "url": "https://docs.laioutr.com/mcp"
      }
    }
  }
  ```
  :::

  :::tabs-item{label="Windsurf"}
  Edit `~/.codeium/windsurf/mcp_config.json`:

  ```json
  {
    "mcpServers": {
      "laioutr-docs": {
        "serverUrl": "https://docs.laioutr.com/mcp"
      }
    }
  }
  ```
  :::

  :::tabs-item{label="Zed"}
  Add to your Zed `settings.json`:

  ```json
  {
    "context_servers": {
      "laioutr-docs": {
        "command": {
          "path": "npx",
          "args": ["-y", "mcp-remote", "https://docs.laioutr.com/mcp"]
        }
      }
    }
  }
  ```
  :::
::

## Using it

Once connected, point the assistant at a question the docs can answer, for example:

- "Using the Laioutr docs, show me how to define a product Section with `defineSection`."
- "Look up the Orchestr query for cart line items in the Laioutr docs."

The client will call the docs MCP server, fetch the matching pages, and ground its answer in them.
