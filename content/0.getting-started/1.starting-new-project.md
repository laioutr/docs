## Operating System Requirements

Laioutr is designed to work on Unix-based systems. Here's what you need to know about operating system compatibility:

### Supported

- Linux
- macOS
- Windows with WSL2

### Not Supported

- Windows PowerShell
- Windows Command Prompt

### Recommendation

For the best development experience and to avoid potential issues, we strongly recommend using Linux or macOS for your Laioutr projects.

## Open Source user

Most of our eCommerce Apps are available in an Open Source model under MIT licenses.

Even though we closely collaborate with App creators, we cannot provide any support for these integrations as Laioutr. When seeking support please use our Slack Channel.

You can find installation instructions for open-source apps in the respective docs.
