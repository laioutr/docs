> **Time** = \{ `time`: `string`; \}

ISO 8601 time string. Must include a time-zone offset.

E.g. "23:30:00-05:00" would represent 6:30 pm Eastern Standard Time (EST) which is 5 hours behind Coordinated Universal Time (UTC).
