##

As described in the [Data Model](/getting-started/data-model) chapter, data in Laioutr is organized into normalized entities. Each entity has a unique id and a type. Entities can have components, which are like columns in a database table.

In order to actually fetch data from your connected data-sources, you need to use the Orchestr API.

For deeper informations about our internal Backend for Frontend "Orchestr", please have a look here.
