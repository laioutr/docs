## Laioutr Cockpit

The **Cockpit** is the web application where you manage Laioutr organizations and storefront projects. It is aimed at **operators, merchandisers, and project owners** who configure hosting, review deployments, browse connector apps, and open **Studio** to edit the live frontend—without working in source code.

Typical entry URL pattern: `https://cockpit.laioutr.cloud/o/{organization}/p/{project}` (your organization and project slugs).

### What you can do here

- **Project dashboard** — quick entry to Studio, Apps, Themes, and other areas.
- **Deployments** — list builds, filter by status and environment, trigger a deploy, and open a deployment for logs and metadata.
- **Apps** — browse integrations (ecommerce, tracking, performance, search, and more) and open each app’s detail view.
- **Studio** — visual editor for pages, sections, and blocks with a live preview.
- **Project settings** — project secret key, NPM registry token, and permanent project deletion.
- **Account** — preferences (language, profile, color mode), security (email, password, delete account), and notification channels.

The sections below mirror the product areas. For developer-oriented topics (framework, APIs, hosting adapters), use **Frontend**, **Hosting**, and **Apps** in this documentation site.
