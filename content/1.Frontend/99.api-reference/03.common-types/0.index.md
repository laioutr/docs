Some shapes recur across many entities, queries, and actions. These canonical types are defined once and reused everywhere consistency matters.

::card-group
  :::card{target="_self" title="Link" to="/frontend/api-reference/common-types/link"}
  Discriminated union returned by breadcrumb items, menu items, and CTA fields.
  :::

  :::card{target="_self" title="Media" to="/frontend/api-reference/common-types/media"}
  Union type returned wherever an entity exposes images or videos.
  :::

  :::card{target="_self" title="Money" to="/frontend/api-reference/common-types/money"}
  Record carried by every price, shipping rate, discount, and cart total.
  :::

  :::card{target="_self" title="Unit Price" to="/frontend/api-reference/common-types/unit-price"}
  Per-unit pricing — used for products sold by weight, volume, or length.
  :::

  :::card{target="_self" title="Measurement" to="/frontend/api-reference/common-types/measurement"}
  Record behind dimensions, weights, volumes, and per-unit pricing inputs.
  :::
::
