Your storefront encounters the **Location** entity when rendering a store locator: the location finder (a searchable list and map of every location) and individual location detail pages. A Location represents a physical place — a shop, showroom, outlet, or pickup point — with its address, map coordinate, opening hours, contact details, status, and media. It has no outgoing links: the finder resolves the full set with [AllLocationsQuery](/frontend/api-reference/location/queries#locations) and filters client-side, while detail pages fetch a single Location by slug.

## Components

### Base

::entity-component-meta{component="base" entity="Location"}
Slug and display name, plus optional store code, source-system external ID, and Google Place ID.
::

### Info

::entity-component-meta{component="info" entity="Location"}
Cover image and short plain-text teaser, sized for finder and list cards so they render without resolving the full gallery or HTML content.
::

### Address

::entity-component-meta{component="address" entity="Location"}
Postal address of the physical location.
::

### Coordinates

::entity-component-meta{component="coordinates" entity="Location"}
Map-marker geo coordinate (WGS84). The single source of truth for a location's position, kept separate from the postal address.
::

### Contact

::entity-component-meta{component="contact" entity="Location"}
Phone, fax, email, and website.
::

### Opening Hours

::entity-component-meta{component="openingHours" entity="Location"}
Weekly opening-hours schedule.
::

### Status

::entity-component-meta{component="status" entity="Location"}
Operational status (operational, coming soon, temporarily or permanently closed) and an optional opening or reopening date. An absent component means operational.
::

### Content

::entity-component-meta{component="content" entity="Location"}
Rich HTML description and "how to get here" arrival text for the detail page.
::

### Media

::entity-component-meta{component="media" entity="Location"}
Full media gallery — all images, plus optional non-image assets such as video — for the detail page.
::

### Attributes

::entity-component-meta{component="attributes" entity="Location"}
Filterable identifier lists: spoken languages, headline features, services and amenities, and accepted payment methods. Known values map to localized labels and icons; unknown identifiers pass through.
::

### SEO

::entity-component-meta{component="seo" entity="Location"}
Meta title, description, and robots directive for the location detail page.
::

## Queries

- [AllLocationsQuery](/frontend/api-reference/location/queries#locations) - Fetch every location for the current shop. Backs the location finder, which searches and filters the resolved set client-side.
- [LocationBySlug](/frontend/api-reference/location/queries#locations) - Retrieve a single location by its slug.
