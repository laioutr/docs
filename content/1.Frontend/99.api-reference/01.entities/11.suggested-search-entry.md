Your storefront encounters the **SuggestedSearchEntry** entity when rendering individual results within a search-as-you-type dropdown. Each entry represents a single suggestion, such as a matching product, category, brand, blog post, page, or query suggestion. Entries are accessed through the `suggested-search/entries` link on a [SuggestedSearch](/frontend/api-reference/entities/suggested-search) entity.

::entity-overview{entity="SuggestedSearchEntry"}
::

## Components

### Base

Type indicator, display title, navigation link, and optional cover image for a single search suggestion.

:entity-component-meta{component="base" entity="SuggestedSearchEntry"}

## Related Entities

- [SuggestedSearch](/frontend/api-reference/entities/suggested-search) - The parent search result that contains this entry.
