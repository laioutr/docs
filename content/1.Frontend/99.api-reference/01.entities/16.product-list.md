A **ProductList** is a saved, named collection of products. One entity covers wishlists, favorites, shopping lists, and B2B requisition lists; the `type` field distinguishes their purpose.

::since-version{version="0.26.0" packages="@laioutr-core/canonical-types"}
::

::entity-overview{entity="ProductList"}
::

## Components

### Base

::entity-component-meta{component="base" entity="ProductList"}
Stable list identity, display details, list type, item count, and custom fields.
::

### Visibility

::entity-component-meta{component="visibility" entity="ProductList"}
Controls whether the list is private, shared within its organization, or public.
::

## Links

- **ProductListItems** → [ProductListItem](/frontend/api-reference/entities/product-list-item) `multi`{color="info"} — Resolves the list's entries.

## Actions

Create, update, duplicate, delete, and mutate lists with the [product-list actions](/frontend/api-reference/ecommerce/actions#product-lists).
