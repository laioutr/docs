A **ProductListItem** is one entry in a [ProductList](/frontend/api-reference/entities/product-list). It stores only list-specific data; current product details and pricing resolve through its product-variant link instead of being copied into the list.

::since-version{version="0.26.0" packages="@laioutr-core/canonical-types"}
::

::

## Components

### Base

::entity-component-meta{component="base" entity="ProductListItem"}
