Your storefront encounters the **Product** entity when fetching catalog data: category listings, search results, and product detail pages. A Product holds general information about a buyable good or service. It is not buyable by itself; instead, each Product links to one or more [ProductVariant](/frontend/api-reference/entities/product-variant) entities that represent the actual purchasable SKUs.

::entity-overview{entity="Product"}
::


## Components

### Base

Product name and URL slug.

:entity-component-meta{component="base" entity="Product"}

### Description

Full HTML-formatted product description.

:entity-component-meta{component="description" entity="Product"}

### Flags

Marketing labels like "New", "Sale", or "Bestseller".

:entity-component-meta{component="flags" entity="Product"}

### Info

Cover image, short description, and brand reference. Used on product tiles and listing pages.

:entity-component-meta{component="info" entity="Product"}

### Media

All product images and videos, including the cover image at index 0.

:entity-component-meta{component="media" entity="Product"}

### Prices

Aggregate pricing across all variants: selling price, strikethrough price, sale indicators, and unit pricing.

:entity-component-meta{component="prices" entity="Product"}

### Rating

Average review score (1-5) and total review count.

:entity-component-meta{component="rating" entity="Product"}

### SEO

Meta title, description, and robots directive for the product detail page.

:entity-component-meta{component="seo" entity="Product"}

### Analytics

Query parameters for PDP links and custom tracking fields.

:entity-component-meta{component="analytics" entity="Product"}

### Brand

Brand or manufacturer name with an optional link to the brand page.

:entity-component-meta{component="brand" entity="Product"}

### Default Variant

Preferred variant ID or option values to preselect on the product detail page.

:entity-component-meta{component="default-variant" entity="Product"}

## Queries

- [ProductBySlug](/frontend/api-reference/ecommerce/queries#product) - Retrieve a single product by its slug.
- [ProductsByCategoryId](/frontend/api-reference/ecommerce/queries#product) - Retrieve multiple products by a category ID.
- [ProductsByCategorySlug](/frontend/api-reference/ecommerce/queries#product) - Retrieve multiple products by a category slug.
- [ProductSearch](/frontend/api-reference/ecommerce/queries#product) - Search for products using a query string.

## Links

- **ProductAllCategories** `Category` `multi`{color="info"} - All categories the product is assigned to.
- **ProductBreadcrumb** `BreadcrumbItem` `multi`{color="info"} - Breadcrumb items for the product detail page.
- **ProductReviews** `Review` `multi`{color="info"} - User-generated product reviews.
- **ProductVariants** `ProductVariant` `multi`{color="info"} - The actual buyable SKUs. A Product must always link to at least one ProductVariant.

## Related actions

- [CreateReview](/frontend/api-reference/ecommerce/actions#review) - Create a new user review for a product.

## Related Entities

- [Cart](/frontend/api-reference/entities/cart) - Shopping session that can contain this product's variants as line items.
- [MenuItem](/frontend/api-reference/entities/menu-item) - Navigation menu entries that may link to this product.
