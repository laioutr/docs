A **QuoteItem** is one negotiated catalog or custom line in a [Quote](/frontend/api-reference/entities/quote). It snapshots enough display data for the quote while retaining a link to the live product variant when one exists.

::since-version{version="0.26.0" packages="@laioutr-core/canonical-types"}
::

::entity-overview{entity="QuoteItem"}
::

## Components

### Base

::entity-component-meta{component="base" entity="QuoteItem"}
Line type, quantity, title, display snapshot, comments, and custom fields.
::

### Cost

::entity-component-meta{component="cost" entity="QuoteItem"}
Negotiated unit price, original list price, totals, tax, and applied fees.
::
