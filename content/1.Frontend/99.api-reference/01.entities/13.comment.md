Your storefront encounters the **Comment** entity when displaying user-submitted comments on blog posts. A Comment holds the author details and HTML-formatted content of a single response to a post.

::entity-overview{entity="Comment"}
::

## Components

### Author

::entity-component-meta{component="author" entity="Comment"}
Commenter name and email address.
::

### Content

::entity-component-meta{component="content" entity="Comment"}
HTML-formatted comment body.
::

## Related Entities

- [BlogPost](/frontend/api-reference/entities/blog-post) - The post this comment belongs to (via BlogPostComments link).
