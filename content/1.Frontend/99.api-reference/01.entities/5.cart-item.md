Your storefront encounters the **CartItem** entity when rendering individual line items inside a [Cart](/frontend/api-reference/entities/cart). Each CartItem represents a single entry: a product, a discount code, or a custom item. CartItems are always accessed through the CartItemsLink on a Cart; they have no standalone query.

::entity-overview{entity="CartItem"}
::

## Components

### Base

::entity-component-meta{component="base" entity="CartItem"}
Item type, quantity, title, subtitle, brand, SKU code, detail page link, and cover image.
::

### Cost

::entity-component-meta{component="cost" entity="CartItem"}
Per-unit price, strikethrough price, subtotal before discounts, and total after discounts.
::

### Product Data

::entity-component-meta{component="productData" entity="CartItem"}
Additional product-specific data such as unit pricing (e.g. price per 100 g).
::

### Quantity Rule

::entity-component-meta{component="quantityRule" entity="CartItem"}
Minimum, maximum, and increment constraints for the item quantity, plus whether the customer can change it.
::

### Availability

::entity-component-meta{component="availability" entity="CartItem"}
Stock status and available quantity for the item.
::

## Links

- **CartItemProductVariantLink** `ProductVariant` `single`{color="info"} - The product variant this line item represents. Nullable; only present when the item type is `product`.

## Related Entities

- [Cart](/frontend/api-reference/entities/cart) - The parent cart that contains this line item.
- [Product](/frontend/api-reference/entities/product) - The product this line item was added from.
