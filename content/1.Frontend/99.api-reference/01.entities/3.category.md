Your storefront encounters the **Category** entity when building catalog navigation, rendering category listing pages, and displaying breadcrumb trails. A Category represents a product grouping in the catalog (e.g., "Shoes", "Electronics") and links to the products it contains.

::entity-overview{entity="Category"}
::

## Components

### Base

Category title and URL slug.

:entity-component-meta{component="base" entity="Category"}

### Content

HTML-formatted category description.

:entity-component-meta{component="content" entity="Category"}

### Media

Images and videos associated with the category.

:entity-component-meta{component="media" entity="Category"}

### SEO

Meta title, description, and robots directive for the category page.

:entity-component-meta{component="seo" entity="Category"}

## Queries

- [CategoryAllQuery](/frontend/api-reference/ecommerce/queries#category) - Retrieve all categories.
- [CategoryBySlugQuery](/frontend/api-reference/ecommerce/queries#category) - Retrieve a single category by its slug.

## Links

- **CategoryBreadcrumbLink** `BreadcrumbItem` `multi`{color="info"} - All breadcrumb items that are part of the category breadcrumb.
- **CategoryProductsLink** `Product` `multi`{color="info"} - Products assigned to the category.

## Related Entities

- [MenuItem](/frontend/api-reference/entities/menu-item) - Navigation menu entries that may link to this category.
