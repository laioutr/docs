The **Glossary** entity represents a term and its definition. Canonical Types defines the reusable component shape; queries, links, and page types are supplied by the consuming content app.

::since-version{version="0.23.0" packages="@laioutr-core/canonical-types"}
::

::entity-overview{entity="Glossary"}
::

## Components

### Base

::entity-component-meta{component="base" entity="Glossary"}
The term's title and URL slug.
::

### Excerpt

::entity-component-meta{component="excerpt" entity="Glossary"}
A short plain-text summary for glossary listings.
::

### Content

::entity-component-meta{component="content" entity="Glossary"}
The full rich-text definition shown on the detail page.
::
