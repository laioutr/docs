Your storefront encounters the **BlogPost** entity when rendering blog listing pages, search results, and individual post detail pages. A BlogPost represents a single article with its content, author, media, and metadata. Posts are organized into **BlogCollection** entities and can link to user-submitted comments.

::entity-overview{entity="BlogPost"}
::

## Components

### Base

::entity-component-meta{component="base" entity="BlogPost"}
Post title, URL slug, and optional publication date.
::

### Author

::entity-component-meta{component="author" entity="BlogPost"}
Author name, email, and optional biography.
::

### Content

::entity-component-meta{component="content" entity="BlogPost"}
Full HTML-formatted post body.
::

### Excerpt

::entity-component-meta{component="excerpt" entity="BlogPost"}
HTML-formatted summary or teaser for listing pages.
::

### Media

::entity-component-meta{component="media" entity="BlogPost"}
Optional cover image for the post.
::

### SEO

::entity-component-meta{component="seo" entity="BlogPost"}
Meta title, description, and robots directive for the post detail page.
::

### Tags

::entity-component-meta{component="tags" entity="BlogPost"}
Array of tag strings assigned to the post.
::

## Queries

- [BlogPostBySlug](/frontend/api-reference/blog/queries#post) - Retrieve a single post by its slug.

## Links

- **BlogPostComments** `Comment` `multi`{color="info"} - User-submitted comments on the post.

## Related Entities

- [BlogCollection](/frontend/api-reference/entities/blog-collection) - The collection this post belongs to (via BlogCollectionPostsLink).
