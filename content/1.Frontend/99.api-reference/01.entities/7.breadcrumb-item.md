Your storefront encounters the **BreadcrumbItem** entity when rendering breadcrumb navigation on product detail pages or category pages. Each BreadcrumbItem represents a single segment in the trail (e.g. Home > Shoes > Running Shoes) and is typically accessed through the [ProductBreadcrumb](/frontend/api-reference/entities/product#links) link on a Product.

:entity-overview{entity="BreadcrumbItem"}

## Components

### Base

::entity-component-meta{component="base" entity="BreadcrumbItem"}
Display name, optional link, and a flag indicating whether this segment is the current page.
::

## Related Entities

- [Product](/frontend/api-reference/entities/product) - Products that include this breadcrumb item in their navigation trail.
- [Category](/frontend/api-reference/entities/category) - Categories that include this breadcrumb item in their navigation trail.
