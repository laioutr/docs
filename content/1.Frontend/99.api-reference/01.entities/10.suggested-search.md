Your storefront encounters the **SuggestedSearch** entity when implementing search-as-you-type or autocomplete functionality. A SuggestedSearch holds the original query string and links to the matching [SuggestedSearchEntry](/frontend/api-reference/entities/suggested-search-entry) entities and [Product](/frontend/api-reference/entities/product) entities returned by the search backend.

This entity is only used for linking. There are no defined canonical components.

::entity-overview{entity="SuggestedSearch"}
::

## Queries

- [SuggestedSearchSearchQuery](/frontend/api-reference/suggested-search/queries#search) - Retrieve suggested search results for a query string.

## Links

- **SuggestedSearchEntries** `SuggestedSearchEntry` `multi`{color="info"} - Individual suggestion entries returned by the search.
- **SuggestedSearchProducts** `Product` `multi`{color="info"} - Products matching the search query.
