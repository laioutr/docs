> `const` **Time**: `z.ZodObject`<[`Time`](/api-reference/common/type-aliases/time)>

ISO 8601 time string. Must include a time-zone offset.

E.g. "23 [30]{ariaLabel=":30:" role="img"} 00-05:00" would represent 6:30 pm Eastern Standard Time (EST) which is 5 hours behind Coordinated Universal Time (UTC).
