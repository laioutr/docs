## Purpose

The **B2B** kit focuses on business-to-business storefront patterns that go beyond classic D2C shopping. It provides components designed for multi-user organisations, role-based purchasing, and decision-heavy workflows.

It is built on top of the shared **UI Kit** tokens so complex UI stays consistent and maintainable.

## What’s inside (typical)

- Account & employee management patterns (lists, roles, invitations)
- Approval workflows (pending/approved/declined states)
- Offer / quote components (status, details, conversion patterns)
- Budget and cost-center related UI (where applicable)

## Best practices

- Keep component names stable to preserve the Studio mapping.
- Prefer composable primitives and properties over one-off bespoke components.
