## Purpose

The **CMS** kit contains content-driven components and sections used for landing pages, brand storytelling, and editorial layouts. It is designed to stay flexible while remaining consistent through the shared UI Kit tokens.

## What’s inside (typical)

- Hero sections and banners
- Text + media sections (image/video), split layouts, feature lists
- Editorial blocks (quotes, highlights, rich content patterns)
- Campaign modules and reusable content compositions

## Variables & theming

- Uses **UI Kit variables** for spacing, typography, colors, and effects.
- Large-scale look & feel changes should be done by adjusting tokens (not by renaming/rebuilding base components).

## Advanced component features

- Responsive, mobile-first Auto Layout structures
- Property-based layouts (alignment, spacing density, media position)
- Instance swapping for imagery placeholders / icons

## Best practices

- Keep naming stable for existing components and variables.
- Build new sections by composing existing primitives where possible to reduce divergence.
