## Agent set-up

Each agent's group in the [Operations Center](/larry-ai/operations-center) links to its **set-up page**. Everyone who sees agents can open it; only those who may set agents up change it (see [Who may do what](/larry-ai/operations-center/who-may-do-what)).

### The set-up page

- **Name**: what the agent is called in your organization.
- **Instructions**: its task, steps and expected output.
- **Triggers**: agents start by hand for now.
- **Projects**: the projects it works in.
- **Tools**: each tool with its mode: **read**, **draft** or **apply**, never higher than the agent allows.
- **Skills**: [skills](/larry-ai/skills) from the organization's library that you enabled; the instructions say when to use them.
- **Credit limit**: an optional cap **per run** and **per month**. Each agent also has a limit of its own it never goes past. Only Owners change it.
- **Model**: the model it runs on, the one Laioutr chose for the agent. On Enterprise, an Owner chooses it from the models the organization's own keys reach (see [Enterprise runs on its own keys](/larry-ai/ai-credits#enterprise-runs-on-its-own-keys)).

**Save changes** saves only what you changed; **Discard** drops it.

### What returns an added agent to draft

For an agent you added (not one of the three every project has):

- Changing its **instructions**, **projects**, **tools** or **skills** returns it to draft. It needs a new test run before it runs again.
- A new **name** or new **credit limits** do not.

### Pause and remove

From an agent's **More** menu, an Owner can:

- **Pause** it: it starts no run. A run it has open ends; what it found stays.
- **Resume** it again later.
- **Remove** it: it leaves the organization's library and runs no more. What it measured, found and proposed stays in **History**.

### Other agents

Beyond the three agents every project has, more agents can be added: with **Add agent** in the header of the Operations Center, or from the **Marketplace**.

1. **Add agent**: adding costs nothing and runs nothing. A project has one agent of each kind. The agent joins your organization's library and starts as a **draft**.
2. **Run test**: runs it once, as it is set up, after showing the estimate. The test is paid in credits. Proposed changes of a test can be rejected, never approved.
3. **Activate**: once the test passed. From then on, everyone who sees agents can start it.

An agent your licenses do not include shows **Marketplace** and **Request** instead of **Add**. A request reaches the Laioutr team; nothing is charged.
