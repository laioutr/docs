## Performance agent

The **Performance agent** measures how fast the environment's live storefront loads, and reports what slows it down. It is there in every project's [Operations Center](/larry-ai/operations-center).

### What it reads

- The live pages, measured with **Google PageSpeed Insights**, on mobile and desktop.
- **Lab data** from Lighthouse, and **real visitors' Core Web Vitals** where Google has enough of them (75th percentile over 28 days).
- The home page of the first active market's default domain, and a category and a product page where their paths are known.
- The home page of every other active market. The charts follow the first market.

The agent only reads. It changes nothing on the storefront.

### Signals

| Signal | What it means | On target at | Critical past |
| --- | --- | --- | --- |
| **LCP** (Largest Contentful Paint), home, category, product page | How long until the main content is visible | 2,500 ms | 4,000 ms |
| **INP** (Interaction to Next Paint), overall | How fast the page reacts to a click or tap | 200 ms | 500 ms |
| **CLS** (Cumulative Layout Shift), mobile | How much the layout jumps while loading | 0.1 | 0.25 |
| **TTFB** (Time to First Byte), overall | How fast the server answers | 800 ms | 1,800 ms |
| **Lighthouse score, mobile** | Lighthouse performance score of the home page on mobile | 90 | below 50 |
| **Lighthouse score, desktop** | The same on desktop | 90 | below 50 |

A value between the two lines is **Watch**. The targets come with the agent; they are not set per project.

### Findings

A finding names the **pages**, **what was measured**, the **threshold** it missed and **what usually causes it**. See [Findings and actions](/larry-ai/operations-center/findings-and-actions).

### When nothing was measured

| The group says | What to do |
| --- | --- |
| Page speed measuring is not set up on the platform yet | Ask support to set it up |
| No active market of this environment has a domain | Give a market a domain, then run the agent again |

### How often it may measure

- At most **4 times an hour** per environment, one every 15 minutes, and **12 times a day**. A larger license can allow more.
- Google's quota is shared by every customer. When it is used up, try again a minute later, or the next day.
- When a measurement is held back, the page says until when.

### What a run costs

- At most **20 credits** a run.
- The estimate is shown before it starts; see [How an agent run is paid](/larry-ai/ai-credits#how-an-agent-run-is-paid).
