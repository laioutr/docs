## SEO agent

The **SEO agent** checks what keeps the storefront's pages from being found by search engines and AI answers. It is there in every project's [Operations Center](/larry-ai/operations-center), in the group **SEO and GEO**.

### What it reads

- The sitemap at `/sitemap.xml` of the first active market's default domain.
- An evenly spread **sample of up to 20 pages** from it.
- On each page: the answer (such as a 404), `noindex`, the canonical, hreflang, the title, the meta description and structured data.

Its counts are of the sample, not of the whole site. The agent only reads; it changes nothing.

### Signals

| Signal | What it means | On target at | Critical past |
| --- | --- | --- | --- |
| **Pages with Schema.org** | Share of sampled pages with structured data | 90 % | below 70 % |
| **Pages with meta description** | Share of sampled pages with a meta description | 95 % | below 80 % |
| **Sitemap pages with 404** | Sampled pages that answer 404 | 0 | 5 |
| **Indexable pages** | Sampled pages search engines may index: no `noindex`, no canonical pointing elsewhere | | |
| **hreflang conflicts** | Sampled pages whose hreflang links point off the storefront, or lack an x-default where there are several languages | 0 | 5 |
| **Duplicate titles** | Sampled pages that share their title with another one | 0 | 5 |
| **Mentions in AI answers** | Not measured yet: shown with example values and marked **EXAMPLE** | | |
| **Average position** | Not measured yet: shown with example values and marked **EXAMPLE** | | |

A value between the two lines is **Watch**. The targets are general defaults of common site-health checks, not a measure of your storefront.

### Findings

A finding names the **pages**, **what the audit found**, the **suggested change** and **why it matters**. See [Findings and actions](/larry-ai/operations-center/findings-and-actions).

### When nothing was audited

| The group says | What to do |
| --- | --- |
| No active market of this environment has a domain | Give a market a domain, then run the agent again |
| The storefront answers no sitemap at `/sitemap.xml` | Publish a sitemap there, then run the agent again |

### How often it may audit

- At most **4 times an hour** per environment, one every 15 minutes, and **12 times a day**. A larger license can allow more.
- This protects your storefront from being crawled in a loop.
- When an audit is held back, the page says until when.

### What a run costs

- At most **20 credits** a run.
- The estimate is shown before it starts; see [How an agent run is paid](/larry-ai/ai-credits#how-an-agent-run-is-paid).
