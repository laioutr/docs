## Skills

A **skill** is a short set of instructions for a recurring task.

- It has a description of when it applies and, if needed, a few files such as examples or templates.
- Skills are stored in the SKILL.md format, so a skill also works in other tools that read skills.
- [Larry Copilot](/larry-ai/larry-copilot) knows the name and description of every skill you enabled.
- He loads a skill's instructions when you choose it, or when it matches what you ask. His answer names the skill he used.
- A skill only tells Larry how to do a task. It grants no permission and never widens what he may do.

### Using a skill in Larry

- Type **/** in Larry's chat.
- The menu lists your enabled skills, **New skill** and the skill library.
- Choose a skill and write your request.

### The skill library

Open **Skills** in your organization's sidebar, or the library from Larry's panel.

- **My skills**: the skills you enabled or made.
- **Discover**: every other skill you may use, searched by name and filtered by where it comes from.

| From | Who sees it |
| --- | --- |
| **Laioutr** | Every organization. A new release applies at once |
| **Organization library** | Everyone in the organization. Its Owners change it |
| **Private** | Only you |

- **Enable for me** adds a skill to your own skills; **Disable for me** takes it out.
- Skills you create are enabled for you automatically.

### Creating a skill

- **New skill with Larry** opens Larry ready to write one, or ask him for a skill in the chat.
- He proposes a draft as a card: its name, description and instructions.
- Creating it from the card makes it your private skill.

A skill's page shows its name, slug, description, instructions and files:

- **Publish vN** releases a new version. It applies at once for everyone who enabled the skill. Earlier versions are kept and listed.
- **Archive** takes it out of use. Larry stops using it from the next answer.
- **Add to organization library** moves your private skill into the organization's library, so everyone there can enable it. Only Owners do this.
- **Used by** says how many people of the organization enabled it, and which of its agents are set up with it.
- **Export SKILL.md** downloads the version in force as a `.zip`: a folder with its `SKILL.md` and its files.

Write a good description:

- The description decides when Larry uses a skill, so say there when it applies.
- The instructions are loaded only when the skill is chosen or matched.

### Skills for agents

- An agent of the [Operations Center](/larry-ai/operations-center) can be given skills from the organization's library on its [set-up page](/larry-ai/operations-center/agent-set-up), beside its projects and tools.
- The agent's instructions say when to use them.
- An agent uses the version it was last saved with.
