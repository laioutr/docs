The following table defines which of Laioutr's products and their components or features are supported at which maximum Support Severity Level. The Severity Levels are defined in [Standard Customer Support](/offering/customer-support/standard-customer-support).

| Product or component                                                  | Maximum Severity      |
| --------------------------------------------------------------------- | --------------------- |
| Cockpit, including Studio                                             | S1: Critical incident |
| Frontend (Frontend Core and Orchestr)                                 | S1: Critical incident |
| Laioutr Cloud                                                         | S1: Critical incident |
| Image                                                                 | S1: Critical incident |
| Checkoutr                                                             | S1: Critical incident |
| Video                                                                 | S2: Incident          |
| AI Search & Discovery                                                 | S2: Incident          |
| Server Side Tracking                                                  | S2: Incident          |
| Distributr                                                            | S2: Incident          |
| Consentr                                                              | S2: Incident          |
| Notifyr                                                               | S2: Incident          |
| AI Personalisation                                                    | S3: Problem           |
| AI A/B Testing                                                        | S3: Problem           |
| AI Engagement & Conversion                                            | S3: Problem           |
| AI Agent Mode                                                         | S3: Problem           |
| Reviewr                                                               | S3: Problem           |
| Translatr                                                             | S3: Problem           |
| Supportr                                                              | S3: Problem           |
| Larry AI and Agents                                                   | S3: Problem           |
| Components provided under open-source licenses, for example App Store connectors | S3: Problem |

Third-party apps and integrations from the Laioutr App Store are supported by their respective provider.

The maximum Severity reflects the business impact a product can cause: S1 for products whose failure can stop transactions, S2 for products whose failure noticeably impairs a production storefront or causes irreversible data loss, and S3 for optimization and back-office functions that fall back to a default behavior. A higher maximum Severity for individual products can be agreed in an Enterprise contract.
