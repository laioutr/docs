Laioutr MCP is a standard remote [Model Context Protocol](https://modelcontextprotocol.io) server. Claude Desktop, ChatGPT, and Cursor are convenience paths to it, but any MCP-compatible client can connect to the same endpoint.

Point your client at the server URL from your organization's [API keys page](https://cockpit.laioutr.cloud/o/_/api-keys) and complete the OAuth flow described in [Connecting to Laioutr MCP](/agent-api/laioutr-mcp/connecting-to-laioutr-mcp). Once connected, your client discovers the available tools through MCP's standard tool listing, so you get the same Studio tools documented in [Supported tools](/agent-api/laioutr-mcp/supported-tools).

::note
Laioutr MCP is in private alpha. The server URL appears on the API keys page only after Laioutr enables it for your organization. A published client SDK and deeper integration guide will follow as the tool surface grows.
::
