## Overview

::callout{icon="i-lucide-construction"}
This page is a placeholder. Laioutr MCP is currently in development — detailed documentation will be added once it ships.
::

Laioutr MCP will be a [Model Context Protocol](https://modelcontextprotocol.io) server that exposes Laioutr projects to AI agents, letting them read project structure and content and make changes through the same APIs that power Cockpit and Studio — without a human driving the UI.

More details, including supported tools and setup instructions, will follow here as the server takes shape.
