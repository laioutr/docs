## Laioutr Agent API

Beyond the [Data API](/data-api), Laioutr offers dedicated interfaces for AI agents to work with your storefronts directly. The first is Laioutr MCP, in private alpha today. More agent-facing access will follow as it ships.

::card-group
  :::card{title="Laioutr MCP" to="/agent-api/laioutr-mcp"}
  A Model Context Protocol server that lets AI agents read and manage your Laioutr projects. Available in private alpha.
  :::
::
