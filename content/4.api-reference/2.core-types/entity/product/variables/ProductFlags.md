> `const` **ProductFlags**: \{ `~schema`: \{ `label`: `string`; `variant`: `string`; \}[]; \}

Array of "flags" that contain marketing-information about a product.

Each item has a label containing the text and a variant for styling.

Examples:
- "New"
- "Sale"
- "Limited Edition"
- "Bestseller"
- "Free Shipping"
