## What is Laioutr UI?

Laioutr UI is a component library that provides a set of accessible and customizable components to build functional interfaces. It is designed to be easy to use and integrate with Nuxt.

It is built on top of UnoCSS, a utility-first CSS framework that provides a set of utility classes to style your components, and Reka UI, an open-source library with unstyled, primitive components.

## What you can build

Laioutr UI is designed to be flexible and customizable, so you can use it to build a wide range of interfaces. While you can build great looking websites using it, Laioutr UI is particularly well-suited for building e-commerce frontends.
