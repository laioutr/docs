## Overview

The **Shop package** is a set of Laioutr UI components for common e-commerce catalog and merchandising experiences. It focuses on reusable patterns for presenting products, building responsive grids and sliders, and helping users navigate long category pages efficiently.

Use these components to compose product listing pages, promotional landing pages, and curated collections while keeping layout, interaction, and styling consistent.
