## Overview

The Newsletter Input component provides an email field and submit button for newsletter signup. It fits in footers, popups, or dedicated newsletter sections and can be used with the Newsletter Registration section or standalone.

## Key Business & UX Benefits

- One control for email capture so signup is consistent across the site.
- Compact layout fits footer and inline sections.
- Accessible label and validation support form best practices.
- Fits standalone or inside Newsletter Registration section.

:::tip
Pro-Tip from Larry: Use Newsletter Input in the footer so signup is always available without a separate page.
:::
