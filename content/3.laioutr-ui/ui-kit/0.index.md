## Overview

The **UI Kit** contains the foundational building blocks of Laioutr UI. These components are designed to be composable, accessible, and theme-aligned, and they form the base layer used by higher-level packages (like Shop, CMS, Navigation, and SaaS).

If you’re building custom pages or components, start here to pick the primitives you need (buttons, inputs, layout helpers, typography, surfaces, and common indicators).
