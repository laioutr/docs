## Overview

The **CMS package** is a collection of Laioutr UI components optimized for **content-heavy pages**: landing pages, editorial content, campaign pages, and branded marketing experiences. The focus is on flexible composition (sections you can rearrange), strong typography and media presentation, and patterns that help users scan content and build trust.

Use these components to quickly assemble marketing pages with consistent layouts while still giving editors room to vary structure and storytelling.
