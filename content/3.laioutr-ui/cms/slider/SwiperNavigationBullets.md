## Overview

The Swiper Navigation Bullets component displays bullet indicators for slider position and lets users jump to a specific slide. It fits sliders and carousels for hero, product, and content sections.

## Key Business & UX Benefits

- Shows slide position and count so users know how much content is available.
- Clickable bullets let users jump to a slide without swiping.
- Compact display fits above or below the slider.
- Theme-aligned styling for light and dark backgrounds.

:::tip
Pro-Tip from Larry: Use Swiper Navigation Bullets so users see slide count and can jump to a slide.
:::
