UI Kit components consume the same value types your connectors produce. Each type has a canonical reference under [API Reference → Common Types](/frontend/api-reference/common-types).

## Media

Images and videos. The [`Media`](/frontend/api-reference/common-types/media) discriminated union carries source URLs, dimensions, alt text, and optional placeholders. Render it with the [`<Media>`](/laioutr-ui/ui-kit/general/media) component.

## Money

Prices, shipping rates, discounts, and cart totals. The [`Money`](/frontend/api-reference/common-types/money) record pairs an integer `amount` (in the smallest unit of the currency) with an ISO 4217 `currency` code. Format it with the global [`$money`](/frontend/api-reference/common-types/money#formatting-with-money) helper. Wrapping types like [`UnitPrice`](/frontend/api-reference/common-types/money#unitprice) combine `Money` with a `Measurement` for "per 100ml" labels.

## Measurement

Lengths, weights, volumes, and counts. The [`Measurement`](/frontend/api-reference/common-types/measurement) record pairs a numeric `value` with a `unit` identifier (the [Laioutr-known codes](/frontend/api-reference/common-types/measurement#unit) like `'cm'`, `'kg'`, `'ml'`, plus the full [ECMA-402 unit names](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#unit)). Format it with the global [`$measurement`](/frontend/api-reference/common-types/measurement#formatting-with-measurement) helper.

## Date

Single instants and timespans. Components take native `Date` objects or `{ min?, max? }` ranges. The global `$timespan` and `$duration` helpers format them in the active locale.

## Opening Hours

Weekly opening schedules with IANA timezone and one-off date exceptions. The [`OpeningHours`](/frontend/api-reference/common-types/opening-hours) record pairs a `schedule` keyed by ISO weekday with optional `exceptions` keyed by `'YYYY-MM-DD'`. Consumed by [`OpeningStatus`](/laioutr-ui/ui-kit/general/opening-status), [`OpeningHoursWeeklyTable`](/laioutr-ui/ui-kit/general/opening-hours-weekly-table), and [`LocationCard`](/laioutr-ui/location/location-card).
