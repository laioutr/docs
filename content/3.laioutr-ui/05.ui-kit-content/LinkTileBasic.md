## Overview

The CategoryNodeBasic component serves as the foundational building block for category promotion outside the main navigation. This is especially important on mobile where the main menu is hidden behind a hamburger. It uses a 1:1 square image ratio with customizable background colors. Flag corner positioning is determined by the node variant to maintain visual harmony. The see-more variant allows linking to supercategory or listing pages with either category IDs or custom URLs.
