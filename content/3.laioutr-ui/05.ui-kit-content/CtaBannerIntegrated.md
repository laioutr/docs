## Purpose

The CTA Banner Integrated component provides a compact promotional solution for spaces where a full-sized banner would be excessive. It combines visual elements like icons with concise messaging to create effective calls-to-action that integrate naturally within content layouts without overwhelming the page design.

## Use Cases

- Secondary promotional placements alongside product listings or category pages
- In-content banners highlighting related services or cross-sell opportunities
- Compact event or sale announcements within blog posts or editorial content
- Support or documentation callouts directing users to helpful resources

## Design Rationale

The smaller sizing options (S, XS) allow this banner to fit within tighter layouts while still providing visual impact through icons and imagery. The inline link option offers a subtler call-to-action compared to prominent buttons, making it suitable for contexts where a softer promotional approach is preferred. Marketing teams can deploy these banners without disrupting the primary content flow.
