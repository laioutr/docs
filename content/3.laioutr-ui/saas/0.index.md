## Overview

The **SaaS package** is a small set of Laioutr UI components tailored for **subscription-based products**. It focuses on the building blocks you need for modern pricing pages: presenting plans, toggling billing cycles, and comparing features across tiers in a structured way.

Use these components when you want a consistent pricing experience that works well across breakpoints and stays easy to maintain as your plans evolve.

## Included components

:::card-group

  :::card{target="_self" title="Plan Card" to="/laioutr-ui/saas/plan-card"}
  A single pricing card showing tier details, pricing, discounts, and included features.
  :::

  :::card{target="_self" title="Plan Card Slider" to="/laioutr-ui/saas/plan-card-slider"}
  A responsive grid/slider layout for displaying multiple plan cards side-by-side.
  :::

  :::card{target="_self" title="Plan Comparison Table" to="/laioutr-ui/saas/plan-comparison-table"}
  A detailed feature comparison table with sections and sticky headers.
  :::

  :::card{target="_self" title="Highlight Toggle (UI Kit)" to="/laioutr-ui/ui-kit/form/highlight-toggle"}
  Monthly/annual style toggle for billing cycle switching.
  :::

:::
