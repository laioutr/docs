## Overview

::tip
For our public Figma Kits, please have a look into our Community Account [here](https://www.figma.com/@laioutr).
::

Fast, accessible, and fully customizable components built for content and commerce. The Laioutr UI Kit and Laioutr UI form the foundation of how frontends are built and managed within Laioutr. Together, they provide a structured, scalable, and business-ready approach to creating digital experiences, without starting from scratch for every project.

The UI Kit is the technical baseline. It defines reusable components, design tokens, and interaction patterns that ensure consistency, stability, and extensibility across all frontends. It gives developers a reliable system to build on, while protecting projects from fragmentation and unnecessary complexity.

Laioutr UI builds on this foundation and turns it into a practical, ready-to-use frontend layer. It transforms technical components into configurable building blocks that can be composed and managed within Laioutr Studio. This enables teams to launch faster, iterate safely, and evolve their frontend over time aligned with business goals and brand requirements.

Together, Laioutr UI Kit and Laioutr UI ensure that digital experiences are not only well-built, but also easy to manage, scale, and optimize as the business grows.

## Laioutr UI Kit

The Laioutr UI Kit is the technical foundation for building frontends with Laioutr. It provides a structured set of reusable UI components, design tokens, and interaction patterns that developers can use to create consistent, scalable interfaces.

The UI Kit is designed to be framework-friendly and extensible, giving teams a reliable baseline while still allowing full customization. It ensures consistency across pages, projects, and brands, while reducing implementation effort and long-term maintenance cost. For developers, it offers predictable patterns and clean abstractions; for businesses, it guarantees a stable and coherent visual language across all touchpoints.

## Laioutr UI

Laioutr UI builds on top of the UI Kit and delivers a ready-to-use, business-oriented frontend layer. It translates technical components into practical, configurable building blocks that can be composed, arranged, and managed within Laioutr Studio.

Laioutr UI is focused on enabling teams to move fast without starting from scratch. It provides opinionated defaults for layout, navigation, and interaction while remaining flexible enough to adapt to brand and business requirements. This approach allows organizations to launch production-ready frontends quickly and evolve them over time without constant redevelopment.
