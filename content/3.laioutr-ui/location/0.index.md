## Overview

The **Location** group covers storefront components for showing a physical store, restaurant, doctor's office, or any other place a shopper might visit. The cards compose the [opening-hours primitives](/laioutr-ui/ui-kit/general/opening-status) from ui-kit with commerce-flavored chrome: a single-line address, a distance string, feature pills (drive-through, accessibility, parking), and action buttons that wire to phone, navigation, and detail links.

The opening-hours primitives themselves live in [ui-kit](/laioutr-ui/ui-kit/general/opening-status) because `OpeningHours` is a Schema.org-style general concept (offices, doctors, restaurants, not commerce-specific). The components in this group encode the storefront placement decisions on top of those primitives.

## Included components

:::card-group

  :::card{target="_self" title="Location Finder" to="/laioutr-ui/location/location-finder"}
  Composite store-locator with search, filters, a list panel, and a Google Maps view. Side-by-side at desktop, tabbed at mobile.
  :::

  :::card{target="_self" title="Location Detail" to="/laioutr-ui/location/location-detail"}
  Single-store detail layout. Top-of-page map plus a slot for header, info list, and any other store-detail content.
  :::

  :::card{target="_self" title="Location Card" to="/laioutr-ui/location/location-card"}
  Compact card for a single store. Two variants: a row-style `list` card for directories, and a `mapPopup` card for map markers.
  :::

  :::card{target="_self" title="Table Opening Hours" to="/laioutr-ui/location/table-opening-hours"}
  Weekly opening-hours schedule built on `BasicTable`. Groups consecutive same-hours days into a single row.
  :::

:::
