## Overview

Optimized for space-constrained layouts like product listing page headers and sidebar filter sections. Supports sale category highlights with dedicated styling variants and promotional flags. Multiple background options (none, light, dark, bright, pale) combined with node variants provide extensive styling flexibility. CTA buttons automatically position navigation to the bottom for balanced visual layout.

## Key Business & UX Benefits

- Compact category slider for listing pages and sidebars so subcategories are visible without crowding.
- Node styles and backgrounds fit different sections and emphasis.
- Auto-hiding navigation and optional CTA keep the slider flexible.
- Promotional flags support sale and featured categories.

:::tip
Pro-Tip from Larry: Use Inpage Navigation Compact Slider on listing pages so subcategories are swipeable.
:::
