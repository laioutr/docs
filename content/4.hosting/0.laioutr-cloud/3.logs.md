[Logs](https://cockpit.laioutr.cloud/o/_/p/_/cloudmetrics/logs) in Cockpit shows your storefront's logs for every
environment on Laioutr Cloud. This page says where a line's level comes from, so the level filter finds what you
expect.

## Where a level comes from

The level is the console method your code called. Laioutr Cloud does not guess it from the text.

| What writes the line | Level |
| --- | --- |
| `console.log`, `console.info`, `console.dir`, `console.table` | Info |
| `console.debug`, `console.trace` | Debug |
| `console.warn`, a failing `console.assert`, a Node.js warning such as `DeprecationWarning` | Warning |
| `console.error`, and the errors Nuxt and Nitro log for a request | Error |
| A library that writes to stdout itself | Info |
| A library that writes to stderr itself | Error |

::note
**consola and pino take their stream's level.** They write to the streams themselves, not through `console`. So
`consola.info` shows as Info, and both `consola.warn` and `consola.error` show as Error. To log a warning that shows
as Warning, call `console.warn`.
::

## One call, one entry

One call is one entry: its stack trace and the objects you passed stay together, printed as Node.js prints them.
An entry keeps 16 KiB of its message; the rest is cut, and the log view marks the entry as cut.

## The lines of one request

A line written while your storefront handles a request carries that request's trace. Open the trace and choose
"Logs of this request" to see the lines it wrote.

## The access log

The access log has a line for each request the gateway served. A response with status 5xx is Error, 4xx is
Warning, a request that got no response is Warning, and every other request is Info.
